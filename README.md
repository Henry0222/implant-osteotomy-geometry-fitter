# Implant Osteotomy Geometry Fitter

**面向 Geomagic Wrap 的种植窝洞轴线、完整侧壁半径与根方圆锥自动拟合脚本**

> Select the complete inner surface, run once, and obtain an axis, a whole-wall reference cylinder, and an apical cone.

[主脚本](./implant_osteotomy_geometry_fitter.py) · 当前版本：1.0.0 · 算法版本：v18 · 适用环境：Geomagic Wrap 2021

Implant Osteotomy Geometry Fitter is a Python script for Geomagic Wrap 2021. It automatically initializes the fitting axis from Wrap's native best-fit cylinder, refines the axis from depth-balanced cross-section centers, computes a whole-wall representative radius, and models the apical cone separately. The final reference cylinder still extends from the coronal boundary to the apical tip plane.

## 项目简介

种植窝洞通常并不是一个理想圆柱。实际 STL 往往同时包含冠方入口、轻度锥形侧壁、壁/锥过渡区和根方圆锥，还可能叠加扫描、翻模与网格处理产生的局部缺损。

如果直接把完整内壁交给“最佳拟合圆柱”，轴线、半径和高度会被压缩到同一个圆柱模型中：根方圆锥可能拉动轴线与半径，网格密度会改变不同区域的影响，而最终半径也未必能代表完整侧壁。

`Implant Osteotomy Geometry Fitter` 将这些参数拆开处理：

| 输出参数 | 几何来源                           |
| -------- | ---------------------------------- |
| 轴线     | 均匀分布的侧壁截面圆心             |
| 圆柱半径 | 完整侧壁半径曲线的轴向深度加权均值 |
| 圆柱高度 | 冠方边界至窝洞最低点               |
| 根方圆锥 | 壁/锥转折平面至窝洞最低点          |

使用时选中完整的窝洞内壁面片并运行脚本，程序会自动完成初始轴建立、冠根方向判断、截面迭代、侧壁/圆锥分离和参考几何创建。

## 为什么要从“最佳拟合”走向“截面迭代”

原生最佳拟合圆柱回答的是：

> 哪一个恒定半径圆柱能够总体描述所选面片？

本项目希望回答的是：

> 侧壁中心沿哪个方向延伸？完整侧壁的代表半径是多少？根方圆锥从哪里开始？窝洞最终延伸到哪里？

两种问题并不相同。对接近标准圆柱的表面，原生最佳拟合通常已经足够；对“轻度锥形侧壁 + 根方圆锥”的窝洞，如果研究重点是轴线、代表半径、入口位置与深度，参数解耦更容易获得可解释、可复核的结果。

本项目仍然使用 Wrap 原生 `BestFitCylinder`，但只让它承担两个有限任务：

1. 提供自动迭代种子轴；
2. 为窝洞根方轴向范围提供补充信息。

原生圆柱的轴线和半径不会直接成为最终结果。

## 一次运行会发生什么

### 1. 自动建立初始轴

脚本首先对完整选区执行一次原生 `BestFitCylinder`，并取得其两个轴向端点。

由于原生端点不保证冠方—根方顺序，脚本会沿候选轴生成 17 个预检查截面，比较轴线两端各 4 个有效截面的中位半径：

- 半径较大的一端判为冠方；
- 半径较小、趋向圆锥的一端判为根方；
- 至少需要 8 个有效闭合截面；
- 两端相对半径差至少需要达到 3%。

如果方向证据不足，脚本会停止并提示检查选区，不会在冠根方向不明确时继续计算。

### 2. 生成两组截面

每轮迭代使用：

- 21 个全深度均匀截面，用于拟合轴线并建立整体半径曲线；
- 根方最后 30% 内的 13 个加密截面，只用于识别短小的根方圆锥。

加密截面不进入轴线拟合，因此不会因为根方采样更密而拉偏轴线。

所有用于轴线计算的截面都必须形成闭合轮廓。均匀截面至少需要 10 个轮廓点；接近锥尖的加密截面至少需要 6 个轮廓点。

### 3. 分离侧壁与根方圆锥

脚本按轴向深度排列有效截面，得到“半径—深度”曲线。曲线经过三点中值平滑后，会比较：

1. 单一直线模型；
2. 侧壁直线与圆锥直线组成的两段模型。

只有当根方半径持续缩小、圆锥斜率明显陡于侧壁，并且两段模型获得足够的统计或几何支持时，根方区域才会被分类为圆锥。转折点两侧各保留一层过渡保护区，不参与轴线拟合。

### 4. 用侧壁圆心反馈迭代轴线

只有均匀采样中被分类为侧壁的截面圆心进入等权 PCA。每轮都会：

1. 按当前轴线重新切片；
2. 拟合各层截面圆；
3. 分离侧壁、过渡区与圆锥；
4. 用侧壁圆心计算候选轴线；
5. 测量轴线角度变化与横向移动；
6. 将候选轴线反馈到下一轮。

单轮稳定条件为：

```text
角度变化 ≤ 0.02°
横向移动 ≤ 0.01 mm
```

必须连续两轮同时满足条件才判定为收敛。最大迭代次数为 20，用于避免破损选区或分段振荡造成无限运行。

### 5. 用完整侧壁计算代表半径

最终圆柱半径不再等于冠方入口半径，而是侧壁半径曲线沿轴向深度的加权均值：

```text
R = ∫ r(z) dz / ∫ dz
```

代码使用相邻截面间的梯形积分实现这个定义。这样，每一段侧壁轴向长度具有相同意义，根方加密截面也不会仅仅因为数量更多而获得额外权重。

根方圆锥不进入圆柱半径计算。若侧壁本身轻度锥形，完整侧壁半径小于冠方入口半径是预期结果，并不代表拟合错误。

### 6. 确定冠方边界与窝洞最低点

轴线锁定后，脚本以 0.05 mm 步长搜索冠方与根方的闭合截面边界，并对根方“最后有效—首次无效”区间做二分细化。

窝洞最低点综合以下信息确定：

1. 闭合截面消失的极限位置；
2. 原生 `BestFitCylinder` 提供的根方轴向范围。

两者都可用时，采用沿最终轴线方向更深的位置。原生圆柱的横向端点位置、最终轴线和半径均不被采用。

## 运行环境

- Geomagic Wrap 2021；
- Wrap 内置 Python 3.7 环境

脚本依赖 Geomagic Wrap 的 `geomagic.app.v3` API，不能作为普通的独立 Python 程序运行。

## 使用方法

1. 下载 [implant_osteotomy_geometry_fitter.py](./implant_osteotomy_geometry_fitter.py)；
2. 在 Wrap 中打开并激活包含窝洞的网格模型；
3. 选择完整的 360° 窝洞内壁，包括根方圆锥；
4. 排除外表面、相邻结构、游离小片和明显入口毛刺；
5. 在 Wrap 的 Scripting 环境中打开并运行脚本；
6. 检查结果窗口以及模型中生成的轴线、圆柱和圆锥。

脚本运行后会在当前模型中添加带时间戳的参考几何。建议先保存模型副本，以便保留原始状态。

## 输出对象

### 完整轴线

```text
OsteotomyAxis_WallAndCone_*
```

轴线从冠方闭合边界延伸至窝洞最低点。

### 全深度参考圆柱

```text
OsteotomyReferenceCylinder_WholeWallRadius_ToApex_*
```

- 半径：完整侧壁深度加权半径；
- 高度：冠方边界至圆锥尖端平面；
- 检测到圆锥不会缩短圆柱。

### 根方参考圆锥

```text
OsteotomyApicalCone_*
```

- 起点：壁/锥转折平面；
- 终点：窝洞最低点；
- 锥尖半径：0；
- 底面半径：与参考圆柱半径相同。

圆柱与圆锥是两套相互重叠的参考几何，不是布尔合并后的实体。圆柱始终延伸到最低点；圆锥用于单独表达根方形态。

### 诊断几何

根据脚本设置，还可生成冠方截面圆、根方最后闭合截面圆、壁/锥转折圆、相应中心点以及原生根方端点。

## 怎样判断结果是否可靠

结果窗口首先应满足：

```text
状态: 已收敛
连续稳定: 2/2
```

随后检查：

- 侧壁圆心 RMS 是否足够小；
- 圆锥是否具有多个有效截面；
- 圆柱半径是否符合“完整侧壁代表半径”的定义；
- 圆柱底面是否位于窝洞最低点平面；
- 生成的轴线、圆柱与圆锥是否在三维视图中贴合 STL。

“原生种子轴 → 最终轴线”的角度只表示原生最佳拟合种子与截面迭代结果之间的差异，不是种植误差，也不应单独用作精度评价。

如果状态为“达到迭代上限”，模型仍会生成结果，但应结合 Scripting 输出检查轴线是否振荡、侧壁/圆锥分类是否反复变化，以及选区是否存在破损或干扰面片。

## 主要默认参数

| 参数                                   |  默认值 | 含义                       |
| -------------------------------------- | ------: | -------------------------- |
| `NUM_SLICES`                           |      21 | 每轮全深度均匀截面数       |
| `APICAL_FOCUS_SLICES`                  |      13 | 根方加密截面数             |
| `APICAL_FOCUS_FRACTION`                |    0.30 | 根方加密范围占全深度比例   |
| `AUTO_ORIENTATION_SLICES`              |      17 | 冠根方向预检查截面数       |
| `AUTO_ORIENTATION_MIN_RADIUS_CONTRAST` |    0.03 | 自动定向所需最小相对半径差 |
| `ANGLE_TOLERANCE_DEG`                  |   0.02° | 单轮角度收敛阈值           |
| `SHIFT_TOLERANCE_MM`                   | 0.01 mm | 单轮横向位移收敛阈值       |
| `CONSECUTIVE_STABLE_PASSES_REQUIRED`   |       2 | 连续稳定轮数               |
| `MAX_ITERATIONS`                       |      20 | 最大迭代轮数               |
| `BOUNDARY_SEARCH_STEP_MM`              | 0.05 mm | 冠方/根方边界搜索步长      |

这些参数是当前数据流程的默认值，不代表对所有扫描精度、窝洞尺寸和网格质量都最优。修改阈值后，应使用已知样本重新验证。

## 方法边界

### 1. 依赖完整周向信息

大面积缺损、孔洞或只有局部弧段时，闭合截面数量会明显下降。

### 2. 假设截面近似圆形

明显椭圆、偏磨或严重变形的窝洞，可能更适合椭圆拟合或轮廓质心方法。

### 3. 壁/锥分段依赖有效半径序列

如果圆锥极短、根方选区缺失或网格破损，脚本仍可能无法可靠识别圆锥。

### 4. 恒定半径不能完整复现锥形侧壁

参考圆柱表达的是完整侧壁的平均尺度。如果目标是精确重建侧壁轮廓，应改用圆台或连续变半径模型。

### 5. 最低点仍部分依赖原生轴向范围

原生拟合不决定最终轴线和半径，但仍可能参与窝洞最低点的轴向确定。


## 当前版本

1.0.0 对应此前的算法 v18，主要特征包括：

- 从完整内壁选区自动建立原生种子轴；
- 自动判断冠方—根方方向；
- 21 个均匀截面与 13 个根方加密截面；
- 侧壁/圆锥自动分段；
- 基于侧壁圆心的反馈迭代与连续两轮收敛确认；
- 基于完整侧壁的深度加权圆柱半径；
- 延伸至窝洞最低点的全深度圆柱；
- 单独生成根方圆锥；
- 精简后的最终结果窗口。
